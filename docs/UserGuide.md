# 智录 使用指南

各功能的完整行为、每一格设置的含义与窗内键位都在这里；快速上手与安装见 [README](../README.md)。


## 截图
全屏 / 区域框选 / 当前窗口 / 多显示器 / 高 DPI。按下热键后整屏冻帧，直接在上面拖框；
遮罩同时认出光标压在的是哪一扇窗口并亮出它实际可见的那圈边界（比窗口矩形准，不含看不见的可调边框），
悬停还会细分到界面元素一级（Windows 走 UI Automation：先认光标下那扇窗，再按包含关系钻到按钮、输入框这些块上，
`,` / `.` 在层级间往上 / 往下走），原地按一下就选此刻亮着的那一块——整扇窗口或最深那一级元素，拖过之后要改就接着拖；
拖完松手即交出，Esc 取消，直接进标注窗；标注窗四周有一圈主色提示线（只上屏、不进成品）。想改截图范围不必回去重框：标注窗默认的「选择」档下拖四边或四角就是重裁，拖动途中新露出的区域用框选那一刻的整屏冻帧预览（不是拉伸旧画布、也不留白边），松手按新范围从同一张冻帧裁；已经画好的标注会跟着裁切平移（撤销栈会清空）。
勾上设置截图页的「标注时显示截图信息」（默认关）之后，标注窗工具栏外侧还会浮一块「截图信息」面板，
按应用、窗口、屏幕、时间四行写明这一帧的来源；取不到的字段分别写「未知应用」「未知窗口」「未知屏幕」
「未知时间」，四项都没取到的轮次（如回溯选帧）不摆面板，右上角的 × 只收起这一轮，
下一次截图照常出现。面板本身不额外落盘：只在本机显示，不写历史、不写日志，也不进成品像素。
另两条来源不同的路要分开看：开了通用页的「截图记忆」后，应用名与窗口标题按那一档的规则进本机索引
（默认关，见[截图记忆](#截图记忆)）；窗口标题只有模板里写了 `%title%` 时才进成品文件名。
它默认关闭是因为窗口标题可能带敏感内容。浏览器地址栏的 URL 这一版不提供，面板与文件名模板都不含网址。
选区落定后四角与四边中点各出现一枚抓点，按住它就是改这一块（鼠标形状会跟着变，
内部按住是整块平移）；方向键整块平移一格，按住 `Shift` 挪右下角一格。拖过头不会把选区翻面，贴到屏边就停下。
拖框途中选区里会浮出三分网格（两条竖两条横的构图参考线，与十字虚线同档：松手就收）。
要**精确**的尺寸或比例也有两条键盘路：裸按 `S` 开一个尺寸输入框，敲「宽x高」回车，选区左上角不动、按这个尺寸铺开；
裸按 `A` 锁上当前选区的长宽比（先框一个相近的再按），之后拖出的框都按这一档来，锁着的档跨轮次记住——想解开再按一次 `A`。
锁着时读数后面会标出「(锁定 16:9)」，不然拖不出想要的形状会被当成手抖；已经框好的块仍可自由拉抓点微调。
光标一进遮罩旁边就跟着一枚放大镜（默认 9×9 像素；设置里「放大镜视野」给了四档——不显示 / 窄（9×9）/ 中（15×15）/ 宽（21×21），
屏幕取色共用这一格），下面一行报这一点的全局坐标与颜色（默认 HEX，裸按 `C` 在 HEX / RGB /
HSL / HSV / HSI / 十进制六种写法之间轮换），卡像素边界时不必先截下来再放大看；贴到屏角时它自己翻到光标另一侧，不会跑出这块屏。
选「不显示」收掉的只是那枚像素插图，坐标与颜色那一行留在原位——要撤的是挡住画面的一大块，不是读数。
拖框时那一行还写着选区的宽高与起点；缩放屏上想要「会被裁出多少像素」那一组数，设置截图页有一格「尺寸单位」（逻辑像素 / 物理像素），
读数、`V` 复制与尺寸输入框三处一起跟着它换——只接一处就会出现「看到的与复制的不是同一组数」。
它不只出现在拖框途中：悬停挑窗口、拉手柄对齐边线、平移选区时同样跟着——最需要像素级读数的正是「按下之前」那一下。
想让它别看某些程序：设置截图页有一格「不参与窗口检测的程序」，填逗号分隔的可执行文件名（如 `chrome.exe, cmd.exe`，大小写不敏感），
写进去的那些窗口悬停时不参与候选识别，手动框选照旧。
平台列不出窗口时退回纯手动框选，不假装这一格有；认不出界面元素时悬停只认整扇窗口，
元素那一级的读数与层级键一并缺席。
截完之后做什么由设置里那一档决定：默认进标注窗，也可以选复制到剪贴板、直接存成文件、
直接贴到屏幕上或直接识别文字——这四档都不弹窗，按下去就落到成品上，
成不成都有句提示（剪贴板与贴图这两步本来没有任何界面变化，不说就分不清「按了没反应」与「已经进去了」）。
另一格「延时截图」等 0 到 60 秒再开始，用来截菜单、悬停提示这类一碰就没的画面；等的时候会说一声，
延时期内再按一次只回一句「上一次还在等」，不叠第二层遮罩。
存成文件时写哪一种格式也可选：PNG（无损，默认档）、JPG、WebP，另有一格质量管着后两种
（「直接存成文件」与贴图右键的「保存」都吃这一档；退出前存的那份恢复数据永远是 PNG，
拿有损档存恢复数据会让桌面每次重启都糊一点，而没人要求过这种事）。图像编码器是插件，
这台机器写不出来的那一档不会摆进设置页——摆出来只会让人选一次、失败一次。
成品文件名那一格还能用截图上下文变量：`%app%`（应用名）、`%title%`（窗口标题）、`%monitor%`（屏幕名），
与 `%date%`、`%time%`、`%ms%` 并用。应用名取进程可执行文件名去扩展名，不是产品友好名；三个上下文值
先清洗再拼进名字（路径字符与空白折成下划线，首尾的点与下划线去掉，每项最多留 40 个字符），
取不到时分别回落成 `app`、`window`、`screen`，不会让保存失败。输入框下面那行「预演：…」用固定示例
（示例应用 / 示例窗口 / 屏幕 1）实时显示将要落盘的主名，留空时显示默认档；模板写歪时显示
「预演：模板不可用」，原因挂在输入框的悬停提示上。预览只在界面上算，不写配置、不建文件。
录屏成品、贴图右键的「保存」与识别结果导出没有截图来源，这三处继续用同一格模板，
三个上下文变量按 `app` / `window` / `screen` 回落。
「鼠标指针」那一格（默认不含）把指针画进成品：形状取的是系统此刻正在画的那一枚，配色与 DPI 都跟着系统走，
按指针的热点落位，尖端指哪儿就在哪儿。区域截图是先画进整帧再裁选区，选区里带不带指针就看它落没落在里面。
滚动长截图那一趟刻意不带——按帧接图会把一枚指针复制成一串。
遮罩里裸按 `P` 可以只翻这一轮：截菜单与悬停提示时想把箭头带上，下一张又想要干净的，为这个去设置里改两趟
不是出路；翻过之后读数后面标出「（含指针）/（不含指针）」，看不见的模式等于没给过这一档。这一档不写回配置，
也只活到这一次交付——托盘、热键、命令行那几路没有遮罩参与，照旧读设置里那一格。滚动长截图那一轮压根不提供
这一档（`P` 在那儿交回系统）。
截图完成还有几处动手就生效的开关（都在截图页）：开「自动保存」之后每张截图立即按上面的格式与目录存一份，
不弹提示（「截完之后」已经选了存文件或快速保存时不重复存）；开「截图音效」响一声系统提示音；
「截图后运行命令」填一条命令行（形如 `上传工具 --path "%file%"`），每一次截图交付完之后起跑它一次，`%file%` 换成这一轮落盘的成品路径；
这一轮没落成文件时（「截完之后」选的是进标注窗那一档）带 `%file%` 的命令会被拒并说出原因，不会把一条不存在的路径喂给外部程序，留空就是不跑；
全局热键「快速保存」（默认 `Ctrl+Alt+S`）不管「截完之后」设的是哪一档，按下就截、截完直接存文件并同时交剪贴板；
标注窗里 `Ctrl+P` 打印，成品按纸面等比居中画上去（打印不关窗——取消对话框或在打印之后接着改，现场都留着）。
「成品加边框」与「成品加投影」两格决定成品离开程序时（存文件、交剪贴板、打印）要不要围一圈框、
带一圈轻投影；贴到屏幕上那一张不加——那是显示，不是输出；存 JPG 时投影底下垫白（JPG 带不了透明通道）。
宽与色也能调：紧挨着多了「边框宽度」（1 到 12 物理像素，默认 2）、「边框颜色」（一段 #RRGGBB，留空回到默认的中灰）
与「投影宽度」（4 到 48 物理像素，默认 16）三格。三格各读各的、各回各的档——哪一格填歪了只把那一格打回默认，
另外两格照收；画布尺寸与绘制拿的是同一份参数，不会出现「框按新值、尺寸按旧值」那种错位。
截图页的「圆角截图」开上之后，区域截图的成品四角切圆（角上是透明像素），紧挨着的「圆角半径」那一格调切多圆
（1 到 60 逻辑像素，默认 12；比短边一半还大的半径自动收一半，不会把内容切光）——整屏、窗口与
滚动长截图不带：那几路的形状改起来各有各的意外。
复制出去的那张在 Windows 上同时挂着 CF_DIB、CF_DIBV5 与 CF_BITMAP 三路（本机探针实测），只认 DIB 的旧程序也吃得到。
标注窗里按 `F5` **就地刷新这一块**：对着同一块屏幕区域重抓一帧换上，画好的标注、选中与撤销历史全部原地留着；
按住不放由键盘自动重复兜住——每一次重复按键就是一次重抓，刷到画面追上为止。刷新走的不是「新截图」那条路：
不响音效、不触发自动保存、也不往最近选区里再记一笔。
滚动长截图（`Ctrl+Alt+L`、托盘菜单与主窗口动作条上都有这一条）：先框出一条要滚的区域，之后按固定节拍反复抓这一块，
每帧自己认出与已接部分的重叠、只把新的一段接下去；过程中浮一条控制条报「已接多少像素」，
按完成就当成一次普通截图交出去（去向仍由设置里那一档决定），按取消整段扔掉。
接的过程中再按一次截图会被当场拒掉并说明「先按完成或取消」——铺第二层遮罩会让手里那张接了一半的图
既没交也没作废。
页面每几行重复一次时接缝会同时对上几个长度，取的是最长的那一个——收短的会把同一段接两遍；
只对上几行（两页开头都是空白）就当没接上，中途换屏或改缩放让宽度对不上时当场报错，
而不是悄悄接出一张歪图。
接缝不比「逐字节相同」那么死：单个像素任一颜色通道差不超过 8、一行里至多约 1% 的像素不同、整段里至多约 2% 的行不同，
都还算接上了——闪烁的光标、贴边的一两条细动效因此不会再让整帧失败；成片的动图、视频与大面积刷新
超过这两档比例时，仍然按没接上处理。
聊天窗与网页常见的固定标题栏、底部输入框也不会每帧重复进长图：首帧顶、底各取四分之一帧高作为参考带，
后续帧的首尾与它连续对上至少 8 行时认成粘性头尾，这一段不再进成品，标题栏只在成品最上方留一次，
输入框整条不进成品；第一次认出来时，已经写进缓冲的那一段吸底尾也一并裁掉。粘性头尾只在整帧对不上
（重叠少于 24 行）时才试着认——整帧能接上就不动头尾，免得把恰好相似的真实内容当标题栏裁掉；认出来之后
每帧仍要原样对上参考带（不少于上次认出的行数）才继续跳过，不再要求整帧对不上；对不上就这一帧重新按整帧判定，
已经裁掉的那一段不会补回来。参考带始终是首帧那一条：标题栏收起会让顶部对不上、从而停止跳过，但输入框变高
是往上长，底边仍与原参考带对得上，多出来的那几行会当成内容接进去，可能多出一条输入框，下一帧也可能因此接不上；
参考带本身不足 8 行的矮帧不启用粘性判定。输入框连同上方一小段内容恰好把整条参考带都对上时（画面几乎没动），
分不清哪几行是输入框，这一帧不裁尾：没有新内容就原样通过，有新内容则按无接缝停下——宁可多留一次输入框，也不裁掉内容。
真找不到可信的重叠时这一轮停下来并说明「这一段和上一段没有可信的重叠」，不会把整帧硬接上去凑一张重复的长图；
按提示回到上一段末尾附近，等画面停稳再滚一小段；一次滚过一屏、两帧之间连 24 行都对不上时就缩小滚动幅度重来，
按取消则整段扔掉。两处边界：新抓的一帧本身矮于 24 行时（一次只挪几行）整帧接上、不判接缝；
往回找重叠最多 1200 行，重叠超过这个数就按没有重叠处理。粘性头尾只按首帧顶、底四分之一帧高的参考带比对，
比这更高的固定栏（把任务栏整条框进选区就是这种）认不全，会照旧留在长图里。

## 拾取界面元素

托盘菜单或 `Ctrl+Alt+E` 打开元素拾取。遮罩铺开后，鼠标悬停会高亮当前界面元素，左上角显示元素名、控件类型与窗口标题；`,` 往上一层、`.` 往下一层，走到最外层就是整扇窗口。

- 原地点击选中当前元素，按元素矩形打开标注窗；直接拖动则回退为普通矩形框选。Esc 取消。
- 元素拾取模式下按 `I` 把元素名、类型、窗口、进程与逻辑矩形复制到剪贴板；普通截图不响应 `I`。
- 元素认不出（自绘界面、高权限窗口、UIA 不可用）时横幅会提示，仍可拖动框选；不会产出 0×0 的图。
- 元素元数据只出现在遮罩横幅与显式复制里，不写历史、不进记忆库、不上传；截图可能含敏感信息，需要时可在标注窗里打码。

## 回溯截图
默认关闭。开上之后，最近一段屏幕画面只留在内存里——不写盘、不上传、不录音，退出程序就没了。
开关在设置 → 截图 → 回溯截图：勾「开启回溯缓冲（仅内存）」会先弹一次确认，把「会把最近 10 秒的屏幕画面保存在内存里。／不写盘、不上传、不录声音。／锁屏或退出程序会清空。／可以排除密码管理器等程序。」四条边界摆出来；
只有点「是」才真的开启，点「否」把勾收回去、配置一个字都不动。关掉开关立即停止抓帧并清空缓冲。
「保留时长」可选 5 到 30 秒（默认 10），「帧率」三档 2 / 5 / 10（默认 5）；
「排除程序」填逗号分隔的可执行文件名（大小写不敏感，写 `keepass` 与 `keepass.exe` 命中同一个进程），名单里的程序在抓帧屏上有可见窗口时自动暂停，窗口关掉自己恢复；
填路径、盘符或通配符不会写进配置，会当场说明正确写法。
内存预算固定 100MB：画面变化才重新编码，没变化时只追加一个时间点复用上一份字节；超出时长或字节预算时淘汰最旧的帧。
托盘悬停提示报「回溯缓冲已开启」或「回溯缓冲已暂停：原因」。

热键默认 `Ctrl+Alt+Z`（快捷键页「回溯截图」那一行可改，与别的全局热键一样）。按下热键，缓冲暂停，在光标所在屏的底部中央弹出胶片条：
每格一张缩略图与 `HH:mm:ss.zzz`，画面或前台窗口变过的帧带一枚候选圆点并标出提示；最近的一枚候选默认选中，没有候选就选最新一帧。
`←` / `→` 移动，`Home` / `End` 到首尾，`Enter` 或双击确认，`Esc`、标题行「取消」或关窗取消；一屏放不下时滚轮横向滚动。
取消只是收起胶片条，缓冲从暂停里恢复。功能没开、缓冲还是空的、正有一轮截图/标注没结束、或延时截图还在倒计时，按热键都只给一句说明，不叠第二层窗。

确认一帧之后在后台解码；解出来就在那一帧所属的屏幕上铺遮罩，横幅写「回溯画面 · 时刻」，提醒这不是实时画面。
之后与普通区域截图同一条路：拖框（历史选区、长宽比锁、`Ctrl+A` 选整屏都在），落定后从这一帧裁出选区，
按设置里「截完之后」那一档进标注、复制、存文件、贴到屏幕上或识别文字。框选取消就回缓冲，不写文件、不记历史。

已知限制：

- 只抓光标所在的那块屏；把光标挪到另一块屏会清空旧缓冲、在新屏重新开始（并说一声）。分辨率、缩放或显示器增减同样清空重来。
- 回溯帧里没有鼠标指针，框选这一轮也不提供「含指针」那一档——缓冲抓的是整屏像素，指针本来就不在其中。
- 不吸附当前窗口或界面元素：画面是历史的一刻，现在的窗口布局可能已经变了，按现在的窗口框只会框错；只做手动框选。
- 打开胶片条、回溯框选与由它起的标注期间缓冲暂停，所以这一段时间在时间轴上是一个洞；不是漏抓，是有意的隐私取舍。
- 普通截图与普通标注（不是从回溯起的）不会暂停缓冲：热键会被拦住不让叠窗，但遮罩与标注窗仍可能被缓冲采到，出现在稍后的胶片条里。
- 隐私确认框的正文写死「最近 10 秒」；「保留时长」调成 5 或 30 秒后，这段说明文字不跟着变，以设置里的那一格为准。
- 导入配置文件（通用页「导入配置…」）会连同回溯开关一起导入，不重弹隐私确认。
- 崩溃转储只写线程栈与异常现场，不含间接引用的堆页：内存里的回溯画面不会随 `.dmp` 落盘。栈上仍可能残留与画面相关的指针或短片段（例如调用参数），但不会构成整帧画面。
- 开启回溯后，带参数的一次性启动（如 `--capture`）也会起缓冲；进程存活期间会抓帧（只存内存），退出即清空。
- 本版只能回看单帧，不能把一段回溯导出成短视频；短片段导出列为 1b 的可选项，不在 Phase 1。
- 本版未做 4K 与 30 分钟连续回看的实测；已测 1440p、10 秒档、60 秒采样，4K 的帧更大，可能更早触发字节预算淘汰。

性能读数（本机 2560×1440、单屏、dpr 1.0，`GYANISSCRIBE_REWIND_GATE=1` 采样 60 秒，预热帧不计入）：

| 档位 | 采样帧数 | p50 | p95 | p99 |
| --- | --- | --- | --- | --- |
| Debug | 5073 | 10.6ms | 12.1ms | 14.6ms |
| Release | 9352 | 6.0ms | 6.4ms | 7.1ms |

开启后空闲 60 秒（不操作桌面）：进程私有内存 130.0 MiB，关闭回溯的基线是 99.7 MiB，差 30.3 MiB；
CPU 用了 3.2 秒 / 60 秒（约 5.3% 单核、0.27% 整机 20 逻辑核）。这是整进程读数，含 Qt 与程序基线，不是缓冲单独一份。
Release 档同一台机器上，抓一帧中位 Qt `grabWindow` 29.1ms、DXGI 桌面重复 9.6ms；一次框选全链中位 13.3ms（5 轮，min 10.6 / max 47.3）。

首帧冷启动（开桌面重复、建暂存纹理与首帧全黑回落）可能到数十毫秒，只有开启后的第一次抓帧会遇到；
真黑屏时 Qt 回落帧本身也是全黑，缓存里没有非黑帧可复用，那一档会每格走一次阻塞回落。
缓冲内存读数与截图链路读数的完整方法见[开发指南 · 性能实测](Development.md#性能实测)。

## 标注
工具十四件：选择（默认，不落笔）、矩形、椭圆、箭头、直线、画笔、高亮、马赛克、高斯模糊、文字、序号、橡皮擦、折线、放大镜。马赛克是「读不出」，
高斯模糊是「还看得见轮廓、认不出字」——对着截图写说明时后者更常用，两者都取底图自己的像素而不是叠一层色。
折线是「点一下落一个折点、双击收笔」的走法（松手不等于落定，最后那段在收笔时并入）；
放大镜拖出一个源框，框里那块底图按 2 倍放大画成旁边的插图（右侧放不下自动翻到左侧），源框自己围一圈虚线标出「放大的是这里」——
它是一面镜子：只照底图自己的像素，别的标注不进插图，镜子照的那块也一个像素都不改；
橡皮擦沿笔迹擦回底图：扫过的地方露出原图那一块，擦掉的是这一刻已经画上去的东西——层叠按画的先后走，
后画的图形照样能压在擦痕上；线宽滑块就是它的粗细；一笔擦除是一步独立的撤销，擦过头按 `Ctrl+Z` 就收回来。
色板、线宽、字号、「填充」（无 / 半透明 / 实心，矩形与椭圆用）、「圆角」（四角按短边比例切圆，矩形用）、「线型」（实线 / 虚线 / 点线，
矩形、椭圆、直线、箭头、画笔、折线六件描边类工具用）、「双向箭头」（箭头两端各一个箭头）、「反向箭头」（把头换到起点那一头：从目标那边往回指，拖的方向与指的方向相反。与双向各记各的，两个都开就是两端都有头）、
「箭头样式」（实心三角 / 空心三角 / 开口两翼：末一档是只有两笔的「→」，杆一直伸到尖上）、
「箭头大小」（小 / 中 / 大：头长相对线宽 2.5 / 3.5 / 5 倍）、
「马赛克粒度」（细 / 中 / 粗）、「高亮透明度」（轻 / 中 / 重）与「高亮加宽」（窄 / 中 / 宽：高亮相对线宽 2 / 4 / 8 倍）各自可选，
「椭圆形状」是马赛克、高斯模糊、高亮、橡皮擦四件共用的形状开关：开着时马赛克与高斯模糊的作用区收进拖框的内切椭圆、
高亮与橡皮擦的两头换圆头圆角，关着则是矩形区与方头那一档（橡皮的方头与圆头同样往外伸半个笔宽，只换角的形状）；
序号有「计数组」三档（第 1..3 组循环）：每一组各自从 1 连排自己的号、点名（`+`/`-`）与「归零」也各记各的，
切组之后再落牌从那一组的下一号接着走；
**色板可以换成自己的一套**：标注页多一格「自定义色板」，填逗号分隔的 `#RRGGBB`（顺序就是颜色菜单里的排列），
留空即内置那八格；填歪的那一次当场点名是哪一格坏了、并且保住上一份好名单（工具栏摆的就是这一格，存歪着切过去会少几格）。
配套两个按钮把这份配色分享出去：「导出色板…」写一个一行一格的文本文件（同事手改两行再发回来也认），
「导入色板…」整份替换——不是往后追加，追加会把两次导入变成两份重复色块。
读坏的那份配置不会把工具栏变成一排空的：记一句警告、回落到内置那八格。
工具栏上颜色只占一枚按钮（按钮上的色块就是当前色）：点开才是色板、最近使用与「自定义颜色…」，
选完菜单自己收起，工具栏因此比原先短了一大截。

**色板按形状各记一格**：给箭头挑了红、再切到序号挑蓝，切回箭头时还是红——同一张画布上「箭头一律红、序号一律蓝」
是写说明时最常见的配色，切一样东西就得重新挑一次色太磨人。没为某个形状挑过色时沿用当前这一格（切个工具颜色就跳，
比多记一格更让人以为程序出错），颜色按钮上的色块也跟着形状走，界面说的就是画出去的那一支色。
**在颜色按钮上滚滚轮调不透明度**：滚一档 5%，最淡 10%、最实 100% 两头夹住（滚到底也不把 alpha 归零，
那一笔会彻底看不见）；滚在工具按钮或滑块上不改颜色，淡掉的这一支同样记在当前形状那一格上，
现在的百分比写在颜色按钮的提示里。
文字还有字体族下拉、粗体 / 斜体与描边 / 背景四个开关，描边开着时「描边色」按钮在 自动（与字色反差）/ 白 / 黑 三档里循环，
「描边粗细」在 细 / 中 / 粗 三档里循环（起点那档就是早先写死的厚度，老图样重画不出第二个粗细）；
背景开着时「底板色」按钮在 自动（与字色反差）/ 白 / 黑 / 用标注色 四档里循环——最后一档把这一形状那支色垫在底下，
字身同时自动换成反差色，否则字压在同色板上等于不存在。落笔后的内容是**多行**的——
行内输入框里回车换行（框随行数长高），`Ctrl+回车` 才会落定；
撤销重做、复制、保存、贴到屏幕上、送去识别、识别二维码与隐私打码都在同一排按钮上，选中的标注可以拖动与删除；
拖完还想挪一像素用方向键（按住 `Shift` 走十像素），不必重画。
选中框上带八个缩放手柄与一枚旋转柄：拖角或边改大小（转过的图形沿它自己的两条边伸缩，拖时按住 `Ctrl` 以中心为不动点、按住 `Shift` 保持长宽比），拖框外的圆点绕中心转角度；
按住 `Ctrl`（反选）或 `Shift`（加选）点几条可以多选，多选整组挪、整组删、整组改样式，各是一步撤销；
`Ctrl+C` / `Ctrl+V` 复制、粘贴副本（副本带一点偏移，连续粘贴一次比一次再挪一格，一次粘贴是一步撤销）；
层叠按画的先后走，后画的压在先画的上面，`Ctrl+Shift+↑` / `Ctrl+Shift+↓` 挪一层、`Ctrl+Shift+Home` / `Ctrl+Shift+End` 直接到底 / 到顶。
打错了字也不必删了重打：双击那条文字，原地弹出带着原文的输入框（光标落在文末），
改完 `Ctrl+回车` 落定——这是一步独立操作，`Ctrl+Z` 回到改之前那一份文字，而不是把整条抹掉；
输入框里按 `Esc` 是取消（重编的那一格不动原文），点到画布别处按「就这些字」落定。
标注不必先从屏上截一块：托盘与主窗口里的「新建空白画布标注」摆一张 1280×720 的白底画布进同一套画布，
写字、画框、把几张截图拼起来说明时不用随便截一块屏当底。它不走截图那条链——没有帧、不记「上次选区」、
不触发音效与自动保存、也不进历史；正因为来源区域是空的，`F5` 刷新在这一轮会自己拒并说明原因（没得可重抓）。
要一张没有底的画布：设置标注页有一格「空白画布用透明底」，勾上之后新开的画布不带白底——透明区在画布上垫一层棋盘格显示
（不垫的话「透明」与「白」在屏幕上长得一样，画完存出去才发现），存 PNG/WebP 留得住透明，存 JPG 前保存那条路会先垫一层白，
不会把透明区涂成黑。默认是白底。

## 美化分享

标注窗工具栏上的「美化分享」把当前成品套进一层模板再交出去；对话框关掉后回到标注现场，画布与图形都还在。

- 内置 4 套模板：留白、聚焦、渐变、代码窗口。代码窗口只做编辑器外观（红黄绿圆点 + 等宽标题），不会把截图里的代码重新着色。
- 右侧可改背景色/渐变、内边距、圆角、描边与投影；水印文字默认空，开了才画，位置可选右下或左下。
- 「另存为模板」把当前样式存到本机设置里，下次打开还能选；自定义模板可删除，内置模板不可覆盖或删除。
- 「复制到剪贴板」与「保存图片…」都按原尺寸导出（预览会缩小显示）；保存支持 PNG/JPEG/WebP，默认目录与文件名沿用截图设置。美化只产出新图：原图、标注与历史都不变，也不跑截图后的外部命令。
- 美化出口不叠加设置里「成品加边框/加投影」那两档，避免两层装饰；模板与设置一起备份/恢复，不上传任何内容。

## 隐私打码
标注窗工具栏右侧有一枚「隐私打码」（复用马赛克图标）：只在你点它的时候检查这一张画布，再点一次才是再查一遍；
它不自动扫描新截图，也不在 `F5` 刷新、保存或复制时偷偷跑。检查只在本机做——文字识别用系统自带的 `Windows.Media.Ocr`
或 Tesseract，二维码/条形码用 zxing；识别文本只在内存里参与匹配，不上传、不写盘，也不写进日志、历史或设置。
检查期间标注窗不关，只提示一句「正在检查敏感信息…」；上一次还没回来时再点只重复这一句，不排第二张。
识别语言沿用设置里「文字识别」页的「识别语言」（默认 `zh-Hans`）。
这台机器没有可用的识别后端时，提示会直接给中文可操作原因（装系统语言包，或换用 Tesseract 语言包），
不会拿一张空清单冒充「没查到」。zxing 没编进来时文字照常检查，清单里不出现二维码项，原因只记日志——
不因为码认不了就整次拒绝。

查出命中项就弹一扇模态的审核窗（标题「隐私打码审核」）：顶部写明「只在本机检测，未上传；请逐项确认，打码后可撤销。」，
清单每行是「类型：脱敏样例」，默认全勾选，可以逐项取消，也可以按「全选」「全不选」。
打码方式下拉只有「马赛克」（默认）与「高斯模糊」两档，按这一轮选中的那一档落笔、不写回设置——下一次打开还是马赛克。
按「应用打码」才落笔：选中的每一处各生成一个马赛克或模糊图形，整批包在一次撤销里，`Ctrl+Z` 一下全退；
落下之后这批图形就是当前选中集，可以立刻拖动、删除或接着改。点「取消」、按 `Esc` 或一项都不选时什么都不改，也不占一步撤销
（一项都不勾时「应用打码」会灰掉，回车也不会接受一份空批次）。
识别是异步的：回来时这一轮已经收场、或画布已经被刷新/重裁（`cacheKey` 变了），旧结果会被丢下并提示
「当前没有正在编辑的标注，请重新截图后再试」或「画布已经变了，请重新点隐私打码」，不会错位打码。

清单覆盖这些类型：

| 类型 | 认什么 | 备注 |
| --- | --- | --- |
| 手机号 | 可选 `+86` 或裸 `86`，`1[3-9]` 后 9 位，允许空格与短横线 | 归一化后校验，前后不得再贴数字 |
| 固定电话 | `0` 开头 2–3 位区号 + 7–8 位，短横线可选 | 避开与手机号重叠 |
| 身份证 | 18 位，GB 11643 校验位，出生日期合法 | 不认 15 位旧号 |
| 银行卡 | 13–19 位数字，允许空格与短横线，Luhn 校验 | 归一化后再算校验和；前缀只作降噪 |
| 邮箱 | 常规 `local@domain.tld`，要求至少一个域名点与 2 位以上字母 TLD | 行级/词级 |
| IP 地址 | IPv4 逐段 0–255；IPv6 只做基本格式校验 | 紧贴字母的版本号不认（`v1.2.3.4`） |
| 二维码/条形码 | zxing 返回的定位四边形外接框 | 后端不在场时这一项缺席 |

OCR 常见的 `O/0`、`l/1`、`S/5` 混淆只在数字型匹配的归一化副本里替换，清单上展示的仍是原文的脱敏样例。
命中优先映射到行内相关词的并集，词框不可用时回退整行；一维条形码的定位框往往只覆盖解码行附近（可能只是一条窄带），
落到画布前会以定位框中心为轴把纵向撑到至少 32 逻辑像素高（原框更高时再补 8），二维码按普通外接框。
两者的物理框都按画布倍率换成逻辑坐标，四周留 2 逻辑像素并夹回画布。
32 逻辑像素能盖住常见的小条码；特别高的条码（例如占满半屏的宽条码）仍可能露出上下边，
落笔后请自己再看一眼。全字母 IPv6（如 `face:beef:…`）与 `Version 1.2.3.4` 这类前面隔了一个空格、
四段又都合法的版本号也在已知漏检/误报范围内。卡号后面紧跟有效期或 CVV、前面隔着年份时，会退回分组边界上
重新找 13–19 位的卡号子段；但成排短数字用空格连在一起时，某个组合也可能碰巧通过 Luhn 被列成银行卡，
互相重叠的候选会合并成一整段，宁可多盖。`861[3-9]` 开头的 13 位真实银行卡会按手机号列（仍会打码，只是类型标签不同）。
一项都没查到时只提示「没有发现可打码的敏感信息。请仍自行检查后再分享。」，不弹空清单——
「没检测到」不等于「安全」：校验位与 Luhn 只降噪，漏报与误报都可能存在，分享前请自己再核一遍。
贴图上的直接标注没有审核宿主，那一扇窗里的「隐私打码」会收起来，只在标注窗里提供。

## Bug 报告

标注窗工具栏的「Bug 报告」把当前成品变成一份可以直接发给同事的 Markdown：对话框关掉后回到标注现场，画布与图形都还在。
报告自动带应用版本、操作系统、Qt 版本、屏幕、截图尺寸与缩放、截图时间，以及截图时的前台窗口与进程；
这些环境值取自这一轮截图本身，不是打开对话框时现查当前屏幕。窗口标题不会自动写进报告标题，窗口段也可以一键关掉。

截图会先用与「隐私打码」同一条本地链路检查一次：手机号、固定电话、证件号、银行卡、邮箱、IP 与二维码/条形码，
检出后默认全部用马赛克打码；点「调整打码…」可以逐项改选或换成高斯模糊。检查期间「复制报告」「保存报告…」都不可用，
避免把还没检查的图交出去。后端不可用、检查失败或截图与检查底图对不上
（包括根本没有可用于检查的底图）时，对话框会写清原因，并且只允许保存文字报告，
不会落一张未检查的 `.png`。没有检出命中项时会明确写「未检出」，但这不等于安全，发送前仍请自己检查。
二维码/条形码的检测依赖 zxing 后端：没编进来时只检查文字，二维码/条形码不会被自动打码，发送前请自行检查。

底部预览按「现在保存会得到什么」显示：会落图的两档在截图段写出同名 `.png` 的相对链接。
「复制报告」只把文字放进剪贴板——截图段恒为「未附带」，预览里有没有链接都不影响这一点；
「保存报告…」按选定的 `.md` 路径写报告，有图时同目录写一份同名 `.png`，
Markdown 里用相对链接引用它。报告只在本机生成：不联网、不上传、不写历史、没有新设置项，关掉对话框后内容不保留。

## 贴图
把图钉在屏幕最上层对着用。滚轮缩放（一格 1.1 倍）、`Ctrl`+滚轮旋转、`Shift`+滚轮调透明度，
左键拖动移动，`R` 转正一挡（`Shift+R` 反向，一挡 90°）、`0` 回到原始比例与角度（透明度不动，那是用户刻意调的一档），左键双击关掉这一张；
`T` 缩到一枚小方块再按还原（缩放与旋转原样留着，只是先让开地方；
那枚方块默认 48 像素，**拖它的四边与四角就给它定大小**，24 到 240 之间随你，中间那一按一拖还是挪它——
方块定多大与那张图缩放到几倍是两件事，退出方块后回到的是你自己调好的那份倍率，这一档也跟着这张贴图留着），
`H`/`V` 左右与上下翻转、`G` 灰度显示、`I` 反色——四个视图变换都只改「看」：复制、保存、标注、识别
拿到的仍是原始像素（与旋转同一条规矩），右键菜单里各有一项、勾选态与键位同解；
方向键把这一张逐像素挪走（裸按一格、`Shift` 十格，与截图遮罩和标注窗同一张键位表；多选时整组按同一位移跟上），
`Ctrl+V` 用剪贴板里那一份换掉这一张——图像、文本卡片与颜色卡片都能换，摆的中心与缩放倍率原地不动，色卡身份也跟着换成的那一份走，
而换上去的像素就是之后复制、保存、标注、识别拿到的那一份（与视图变换相反，这一条是真的换了内容）；
动图这一档当场拒并说明出路：下一帧会把换来的那份盖掉，先存成静态图再贴一张来换。
`Ctrl`+左键点几张可以**多选**（选中的那一圈加粗描边）：拖着其中任意一张，整组按同一位移一起挪；
Ctrl+滚轮转、Shift+滚轮调透明度仍只动这一张，而普通滚轮缩放整组按同一倍率跟着缩；
右键菜单里那句「已选中 N 张」下面是整组入口——关闭 / 保持置顶 / 鼠标穿透 / 缩到小图 / 四个视图变换都对整组生效，
另有一项「批量保存（N 张）」把这几张逐张按设置里的目录与命名模板写成文件（同一次里撞名的自动让位；
成几张、几张没写成与第一条原因都在提示里说清，一张都没写成时那句就是能做的事——换个目录）；
内容相关的标注、裁剪、取色、识别与单张「保存」仍只动这一张，末尾一项「取消选择」；
`Esc` 在多选里先清选择、再按一次才关这张；切组与「全部收起」都会清掉选择；
右键菜单「背景色」给这张垫一层底色（跟随主题 / 白 / 黑 / 灰 / 自定义…）：透明像素处露出来的就是它，
与别的视图变换一样只改「看」、不进成品；不垫时露的是主题的窗口底色（这张窗口本就不是透明背景）；
右键菜单「透明区」管带透明通道的那张图，透明像素底下画什么，四档：跟随窗口底色（一直以来的那一档）、
桌面透出（整窗改逐像素合成，那几块把底下的桌面让出来）、深色棋盘 / 亮色棋盘（按 8 像素一格垫一片棋盘，
看清透明的边界在哪；深浅两档是因为底上可能是白文档也可能是深色桌面）。棋盘同样只改「看」、不进成品，
这一档跟着这张贴图存进布局，重启回来还是它；整张图不透明时这四档看不出差别。
右键菜单「只显示这一张」把屏幕腾给它（其余的先收起来），再点一下原样摆回——
新贴一张、切组、整桌收起或主角自己被关掉时这一档自动落掉；
右键菜单「裁剪」进裁剪态：拖一个框（框外压暗）、回车或双击裁到那一块，`Esc` 原样退出——
进裁剪与进标注一样先把旋转与翻转摆正、退出时恢复；动图的「裁剪」与「标注」一道灰掉并写明出路
（裁完会被下一帧盖回原尺寸，先另存成静态图再贴一张来裁）；
右键菜单复制 / 复制为文件 / 自定义尺寸… / 保存 / 识别文字 / 标注 / 取色 / 裁剪 / 缩到小图 / 保持置顶 / 鼠标穿透 / 窗口阴影 / 平滑缩放 / 关闭 / 销毁这一张，`Esc` 关闭本张；
拖四边与四角也能改大小：光标挨着那一条边就换成对应的双头箭头，按住拖就是把这一张等比放大缩小
（与滚轮、右键「自定义尺寸…」同一档倍率，只等比不拉伸；抓哪条边就以对面那条为锚，拖右边时长出去的是左边在退）；
贴图中间那一片仍是整张平移的落点。
关掉这一张分两档，差别只在**还按不按得回来**：「关闭」与 `Esc` 是同一条，摘掉之前把像素抄进「最近关掉的贴图」那份册子
（最多五张，最新在前），托盘上「重新贴出最近关掉的贴图」按一次报销一张——贴回光标处，连来源文件一起带回来（动图接着播），
提示会说还剩几张可报，册子空了也说一句而不是静默；「销毁这一张」摘得干净，不抄那一份像素，托盘那条再也碰不到它。
整桌收起与切组都不算关掉（图还在册）；「关闭」在整组入口里对全组生效并逐张抄进册子，「销毁」刻意不放进整组——
一次毁掉一桌太顺手了，手滑的代价在这里是拿不回来的像素。
「复制」交的是像素（粘进文档是一张图），「复制为文件」交的是一条本地路径（粘进资源管理器/聊天窗口落一份 .png，
落在缓存目录里、按内容起名，同一张图重复复制复用同一个文件）。
「自定义尺寸…」把滚轮的一格一格换成精确值：敲「宽x高」（与截图选区那个输入框同一套写法），或填一个倍率（`2x`、`1.5X`、`50%`，也认纯数字的 `0.5`）——倍率按这一张当前的尺寸算，超界的值夹在缩放区间里；
按宽缩放、高跟比例走——想两维都吻合就先裁成那个比例；超界的值夹在缩放区间里。
「窗口阴影」给这一张围一圈投影（几圈递减的暗晕）：窗口比内容每边大一圈，内容坐标、选中框、
取色与吸附位置全都不动——内容在窗口里居中，留边出现或消失对它零影响；缩到小方块（T）时不带。
右键菜单里的「平滑缩放」管放大时怎么铺像素：开着按插值铺平，关掉则一格源像素就是屏上一块硬边方格——
放大到两三倍读截图里的小字时，插值会把笔画糊成一片灰，关掉才认得出那一格是什么。它与四个视图变换一样
只改「看」：复制、保存、标注、识别拿到的仍是原始像素，默认开着（与 Qt 的绘图缺省档一致）。
`0` 是唯一的复位出口；左键双击是「看完了，关掉这一张」，不碰缩放与角度。
右键菜单里的「标注」就是**在贴图上直接标注**：整窗变成一张标注画布（工具、快捷键、撤销与标注窗完全同一套），
`Esc` 收工把画上的东西烘进这张图——贴图不关，这是「给它添一笔」而不是「丢弃」；
工具栏上复制 / 保存 / 贴到屏幕上 / 识别文字四个按钮（以及回车、`Ctrl+S`、`Ctrl+D`、`Ctrl+O`；打印只在 `Ctrl+P` 上）
都是「收工并做这件事」；「贴到屏幕上」是把成品**另贴一张**新图（留底再贴一份），不动原张。
旁边还有「识别二维码」：认出画面里的二维码/条形码就把文本复制进剪贴板，认没认出来都**不关窗**——
多半只是想知道「这里头是什么」，顺手关掉现场是最烦的一种收场（与打印同一条口径）；
一张图里有多个码时优先挑二维码（一维扫描在二维码的花纹里偶发假阳性），提示里报出认出几个。
后端是 zxing-cpp（Apache-2.0，许可证正文随包发；没编进来时按钮报明原因）。
旋转过的贴图进入时先转正、收工转回原角度（批注跟着图一起转）；贴边收着的不在标注中收回；
动图的「标注」是灰的——标注会被下一帧盖掉，先另存成静态图再贴一张来标。
盘上的文件与链接可以直接**拖到贴图上**贴成新图：图片文件按盘上的像素读出来（GIF 这类动图贴上去接着播），
网页链接渲染成文本卡片，纯文本与颜色写法和剪贴板那条路一样各有卡片；拖进来几张就贴几张，
后一张向右下错开一格；不是图片的文件不拦整次拖放，能贴的照贴，贴完那句提示会点名哪些没贴。
退出前把还在桌上的贴图连像素一起记下，下次启动摆回原位——置顶、鼠标穿透与「收起全部」那一档
也一起记：不置顶的那张回来还是不置顶，穿透过的还是穿透，「收起 / 摆回全部贴图」那一档状态照旧
（托盘上那句就是出口）；某张图被清掉时只跳过那一张。
开着鼠标穿透的贴图收不到右键，也就关不掉自己那一档——托盘上「取消全部贴图穿透」就是这条死路的出口（没有这能力的平台上这一条根本不放），
按下去说清恢复了几张，一张都没开时也说「没有贴图开着鼠标穿透」，不让人以为程序卡住了。
要临时把桌面清干净不必关掉贴图：托盘与 `Ctrl+Alt+H` 那一条把整桌一起收起来，再按一次原样摆回——
收着的图还在册（张数、摆位、缩放、透明度都不动），只是不在屏上；因为收着的时候点不到它，摆回这一格也只放在托盘与热键上。
托盘上还有一条「把剪贴板里的内容贴到屏幕上」，按一下就在光标处落一张贴图：剪贴板里是**图像**就原样贴；
是**一段纯文本**就渲染成白底深字的卡片（宽度封顶后折行，一个断不开的长词按字符断，最多 2000 字）；
是**颜色写法**（`#`、`rgb(`、`hsl(` 开头的短单行）就渲染成色块加写法条的颜色卡片——把「red」这类普通单词
当成颜色、或者把一段英文渲染成色卡，都是不做的，只认那三种写法。贴出来的色卡之后还能改色：右键「改这一张的颜色…」
（只在这一张是色卡时才出现）打开取色器，选完当场重画这张卡，条上写的写法跟着设置里 HEX 字母那一档走；
`Ctrl+V` 把内容换成别的一份时这个身份跟着变——换成照片或文本就把这一项摘掉，不会在一张照片上留下一个改色入口。
剪贴板里或拖进来的是**一条网页图片地址**（`http:`/`https:`）时，程序会去把它取回来贴成图：只认这两种协议、15 秒超时、32 MB 上限，
按服务端给的 content-type 判是不是图片（不是就拒并点名它给的是什么）；取不成、太大、太慢、读不出像素，各有一句中文原因。
剪贴板里是**文件**（资源管理器里复制的那一份）
就走拖放那条转换：图片贴出来（多件依次错开、动图连来源带走继续播），一件都不是图片时给一句说明而不是静默。
贴图可以分组摆放：每张贴图在右键菜单里「移动到分组」——列出现有分组和一项「新建分组」，
移出当前组的那张先收起来（换组放着＝腾地方）；桌上只放当前组，`Ctrl+Alt+G` 或托盘里那条
「切到下一组贴图」在现有分组之间轮换，切到哪一组会有提示。分组号与当前组都跟着贴图布局记下，
重启后回到同一组；某一组的贴图全被关掉时这一组就没了，当前组自动回落到第一组。
轮换的顺序还能自己排：通用页那一格「分组轮换顺序」填逗号分隔的组号（如 `3, 1, 2`），切组就照这一圈走；
没写到的组补在末尾、不在册的组号跳过，所以新建的一组立刻切得到，不必先回设置里补一笔；留空即按组号升序，
填歪（非正整数或同一个组写两次）的那一次不写进配置，提示会点名是哪一格——同一组在一圈里出现两次，切组就会多跳一步。
分组还能起名字：同一个子菜单里「重命名这一组…」敲一个字（留空就是取消命名，回到「分组 N」这种叫法），
起过名字的组在菜单与切组提示里都念名字（`分组 2：参照对比`），号还是那个号——名字只是挂在后面的标签，
不替掉它，布局与切组都按号走。同处还有「删除这一组」：把这一组的贴图并回第一组（不是扔掉），名字跟着清掉；
第一组是并回来的落点，那一项在它上面是灰的并写明原因。名字跟着组一起过夜也一起消失：组空了名字就没了，
不会留下挂在看不见的组上的标签。
全桌的分组还有一扇专门的窗：托盘与主窗口动作条里的「贴图组管理…」（开着就不开第二扇，只抬那一扇并重读一遍），
三列一张表——哪几组在册、各有几张、哪一组此刻摆在桌上。张数算的是**在册**的而不是看得见的：收着的与在别组的那几张
都属于这一组，按看得见的算就会少报，看着像那张图没了。选中一行才能按下四个动作（没选中时按下去也不知道该管哪一组）：
「摆出这一组」把活动组换成点名那一组（没人的一组的拒绝会说清怎么把图挪过来，切过去等于把整桌收空，那种事不做）；
「重命名…」与右键那一条同一个出口；「腾空这一组」关掉这一组在册的全部贴图，走的是**关闭**那一档而不是销毁——
提示里跟着说清「还能按回最近 5 张，更早的找不回来」；「删掉这一组」把成员并回第一组、名字跟着清，
删不掉第一组那句拒绝住在管理器里，界面上不另写一套「哪些组能删」。
表上不摆空壳组：本仓的一组由「有贴图在册」成立，所以这里没有「新建一个空组」那一条——
新建一组的路径是右键「移动到分组 → 新建分组」，一句出路写在空表的提示上。
右键菜单里还有一条「取色」：进去之后鼠标变成取色笔，悬停出读数（写法跟着设置里那一档走），
点一下就把那一像素的颜色复制进剪贴板，取完自己退出；这一档里 `Esc` 只退出取色，不关贴图。
「保存」按设置里的目录与命名模板写一份，「在文件夹中查看」先写一份再打开那个目录——
贴图的像素在内存里，没有别的「它所在的文件夹」。
贴图拖到屏边附近松手会贴上去（吸附容差默认 12 像素，设置贴图页「吸附距离」可改，填 0 就是完全不吸；
越界的先夹回屏内——夹回来之前能把一张图整个拖出屏幕，从此再也点不到）；贴边之后指针一离开就收成 6 像素的一条，悬停再展开，右键菜单里
「贴边隐藏」也能直接收发这一档，拖离屏边自动脱开。
按住 `Shift` 拖动时，这张图会吸向**桌上其他贴图与屏上别的程序窗口**的边线：六条线一起比（左 / 中 / 右、
上 / 中 / 下），每一轴取位移最小的那一条，容差就是上面那一格（贴边与对齐两处同一把尺子，两处各读一份就会差出一格）
——只比外边线的话，一窄一宽两张永远对不齐中心。
参照在起笔那一刻取一次快照、整趟拖动都用它，不然每帧重新枚举一遍窗口就把鼠标移动拖慢了；不按 `Shift` 一律不吸，
自由摆放的手感不被参照抢走。`Ctrl+A` 把桌上看得见的贴图一起选进多选集（收着的与在别组的那几张不算——
整组动作落到看不见的图上，比没生效更难解释）。
不想让某张被拖变形：贴图页有一格「不许拖边改大小」，勾上之后按在边带与手柄上不再是改尺寸，而是整张平移——
关的是改尺寸的**落点**这一处，光标、按下分派与拖动手柄都跟着它，不会出现「光标说能改、点下去没反应」；
滚轮缩放、右键那几档与整张平移都不受影响，默认是关（与本仓此前的形状同值）。
动图（GIF/APNG）贴上去会接着播：只认「文件」这一条来路（历史那页贴出来的、以及上次会话留下的
动图），来源路径跟着布局记下，重启后接上继续播；剪贴板与标注贴出来的图在内存里，没有帧序列可播。
藏起来或收起的动图会停下，不在屏上就不烧 CPU。

## 屏幕取色
全屏冻帧 + 放大镜，点一下按选定格式（HEX / RGB / HSL / HSV / HSI / 十进制）把颜色复制走。
放大镜那一枚的大小跟着设置里「放大镜视野」那一格走（与截图遮罩同一格，四档含「不显示」）：
「不显示」收掉的同样只有插图，光标处的坐标与颜色文本照旧读得出。
HEX 那一形里字母用大写还是小写是单独一格（`Pick/HexUppercase`，默认大写 = 本仓此前的唯一写法）：
粘进 CSS 与不少前端工具里常见的是 `#3c78c8`，而这一档只动 HEX，其余五档逐字节不变。
三处读数（取色遮罩、截图遮罩的放大镜、贴图右键的取色）现读这一格，复制走的那一串与屏幕上看到的同一形。
遮罩底边还摆着一行「最近取色」的色块（最多 8 条，最新的在前）：点色块或按数字键 1–8 就把那一档取回，
不用回到原处重新对像素。贴着屏幕取色与贴图右键的取色共用这一份记录——从哪儿取的色都在这一行上。
存进配置的最近取色仍是固定的大写 `#RRGGBB`：那是存储的形状，不是复制出去的形状，跟着这一格走会把已有清单判成坏值。

## 录屏
范围可选整屏 / 上次选区 / 当前窗口，输出可选 MP4 / GIF，帧率、画面码率、最长录多久（秒，默认 600 = 10 分钟，上限 7200 = 2 小时；到点自动收尾并保存，控制条上「已录时长」的提示写着这句）、光标高亮、倒计时秒数（0–10，0 表示立即开始）、
视频编码器（自动按偏好顺序逐个真探，也可以钉住某一家；GIF 档下帧率那一格自动收在上限 24，切回 MP4 恢复你原来那一档）、
麦克风与系统声音各自可开（两路都开时混音）。控制条显示状态、时长与 3-2-1 倒计时，
可暂停、可取消（这一段整段扔掉：不封盘、不起编码、临时帧当场删掉），可贴边、可最小化到托盘——
收起后托盘那一行仍报「正在录制 / 已暂停 + 时长」。停止之后再按取消会被拒，理由说在提示里
（那一份帧正是后台编码在读的输入）。
停止后编码在后台线程进行，界面不冻；编码器在编码前用真 `ffmpeg` 探一遍，取第一个开得起来的。
抓帧在 Windows 上走 DXGI 桌面重复（抓一帧中位 6.0ms），开不了这套原语的机器回落 Qt 的 `grabWindow`
并在日志里点名用的是哪一套。

## 步骤记录

托盘菜单或 `Ctrl+Alt+T` 开始一次步骤记录；首次会先说明会记录点击坐标、前台窗口标题/进程与整屏截图，全部只在本机、不上传。录制时屏幕顶部有一条控制条，随时显示已记步数，可暂停/继续/停止；暂停会真正停掉监听，不是只在后台丢事件。没有托盘的环境里，主窗口操作栏上有同名入口，默认热键不变。

- 只记录左/右键点击与前台窗口切换；滚轮、拖拽、键盘不记录。按下与抬起之间位移不超过 6 逻辑像素才算一次点击，更大的位移按拖拽忽略。每条步骤抓整屏（多屏时是事件所在的那块屏），说明自动取界面元素名与控件类型，取不到就写坐标。截图本身不烧标记：预览与导出时才在点击处现画红圈与序号，序号按当前顺序取，删除、上移/下移后自动重排，导出前怎么调都不用回头改图。
- 停止后进入审核窗：可改说明、删除、上移/下移、补一步；核对后自行导出单文件 HTML 或 PDF（A4）。放弃会删掉临时截图；导出成功后先保留，便于再导另一种格式，关闭审核窗时一并清理。
- 不做自动打码：截图与说明可能含敏感信息，导出前请自行检查、删改。步骤只在内存与 `Unsaved/Steps` 临时目录中，关闭审核窗或放弃后清理；不写历史、不进记忆库。程序启动时会清掉超过 24 小时的旧会话临时目录。
- 录制中不能再开始截图/录屏/回溯；先停止步骤记录。托盘菜单被截进画面时可用控制条或热键停止。

## 文字识别
`Windows.Media.Ocr`（用系统自己装的语言包，无需放文件）与 Tesseract 两个后端，按平台与可用性自动选型。
结果窗口左侧原图、右侧文本，点一行就在图上圈出那一行；可导出 TXT / JSON，可换语言重认。
托盘还有一条「识别图片文件…」，挑盘上的一张图直接认。

结果窗口在摘要与底部按钮之间还有一排内容动作：只要认出了文字就有「复制 Markdown」，把这一份结果按排版转成 Markdown 放进剪贴板；
检测到简单表格时多一枚「导出表格 CSV」，摘要追加「· 检测到表格，可导出 CSV」；复杂表格不提供导出，
只在摘要后追加「· 检测到复杂表格，暂不支持 CSV」。
表格检测只认一张表，且只支持简单表：合并单元格、多级表头、文字跨列、行内缺格或各行格数对不上都会判为复杂表，
这时 CSV 按钮不出现，可改用「复制全部」「复制选中」或导出 TXT 取回文字本身。
检测只读词框对齐，是尽力而为的启发式：同一格里的词距过宽会被拆成两格，紧贴表格上方的单行短标题
可能被并进候选段而判成复杂表或稀疏表，导出前建议对着原图核对一遍。

CSV 按 RFC 4180 写：字段里的逗号、双引号与换行按需加引号、引号成对转义，行尾用 CRLF；
文件开头写 UTF-8 BOM，Excel 双击打开中文表头不会乱码。Markdown 的排版是启发式的：
短行行高达到正文的约 1.15 / 1.35 / 1.6 倍时分别升为三级 / 二级 / 一级标题；行首是 `-`、`*`、`•`
或 `1.`、`1)`、`一、` 这类符号与编号时按列表输出，缩进按字符宽折层、最多四层；
连续至少两行带缩进、含代码符号或基本全是 ASCII、且不以中文句末标点 `。`、`！`、`？`、`；` 结尾时包成围栏代码块，
单行不成块，相邻行缩进差超过 0.5 个字符宽就断开；只有整段缩进一致的平铺代码会被围栏，
词框之间的内部缩进不会重建，复制成 Markdown 后需要自行补排版；
表格走上面的检测，简单表写成首行表头加分隔线的 Markdown 表格。段落按行距合并，行首会被 Markdown 误认成标题、列表或引用的字符会转义。
误判时最省事的出路是用纯文本：复制全部、复制选中或导出 TXT 拿到的都是原样文字，不做任何排版。

这些动作只处理用户主动发起识别后的这一份结果：不自动 OCR、不后台扫描，也不上传任何内容；识别与排版都在本机完成。

## 命令行
不带参数启动即常驻。带参数就是「跑一件事」的启动：一次性动作都不锁单实例，托盘里常驻着一份时照样能截图、
贴图与取色。`--selftest` 是同一档里更重的一条：它同样不锁单实例，但要真的建控制器、装托盘、开窗口并登记一次
全局热键，退出码 0 只在日志就绪且固定热键与自定义绑定全部登记成功时给出；热键被别的程序占着时给 1，
读数里会列出固定与自定义两组各有多少条没登记上。
`--capture=full|region|window` 截一张，默认存成文件并复制进剪贴板，把文件路径打到标准输出、退出码给成败
（`region` 用记下的「上次选区」，没有记过时当场报错）；`--pin <文件>` 把盘上的图片贴到屏幕上（保持运行）；
`--pick` 进入屏幕取色（保持运行）。
交付去处可以点名：`--to=file,clipboard,pin` 一次落几处，逗号分隔，交付顺序恒为「存文件 → 剪贴板 → 贴到屏幕上」，
认得的只有 `file` / `clipboard` / `pin` 这三个词（区分大小写，写歪、写重、多写一个逗号都当场拒绝并列出可取值）；
点了 `pin` 就不再退出——那张贴图属于这个进程，退出会把它一起带走，与 `--pin` 同一档做法。
截完还能接着跑一条外部命令：`--exec="上传工具 --path %file%"`，参数里的 `%file%` 换成这一轮落盘的成品路径；
这一轮没落成文件时带 `%file%` 的命令会被拒并说明原因（不给它喂一个不存在的路径）。
设置的截图页有同一件事的日常档：「截图后运行命令」，每一次截图交付完之后跑，命令行给了 `--exec` 时以那一条为准。
`-h` / `--help` 打用法说明，`-v` / `--version` 打版本号；参数写错、一次给了两个动作、或把 `--to` / `--exec` 配到
`--pin` `--pick` 这类没有「截完之后」这一步的动作上，都会当场拒绝并附上用法说明（退出码 2）。

## 历史记录
写出过文件的成品进列表（缩略图 + 时间 + 类别 + 尺寸）：「直接存成文件」、标注窗的「保存」与录屏编出的成品都算，
只复制到剪贴板或只贴到屏幕上的那一次没有文件，默认也就不进列表。通用页的「未保存的截图也进历史」拨开之后，
那一张会在程序数据目录下的 `Unsaved` 里留一份无损像素（永远写 PNG，透明通道不丢；最多 50 张，超出按写入时刻裁掉最旧的，
目录里别人放的文件不动），于是误触 `Esc` 丢掉的那一张也还在列表里——写不进去会当场说一句，不会静默假装留过了；
这一档默认关，开着它每截一张就往盘上多一份。录屏那一类不解视频帧，缩略图取不出画面时摆一枚类别图标。
尺寸读不出时列表文案不带那一格，而不是打一个「0×0」冒充读数。可按文件名、类别或日期搜索，可按类别筛选，
次序固定时间倒序；列表空了会写一句「还没有记录」引导，筛选没命中则提示换关键词或类别。每条可以贴回屏幕上、送去识别、打开它所在的那个目录，或单独移除；「清空列表」一次去掉全部记录，
会先问一句，且动的只是清单——成品文件留在各自目录里，软件不替用户做不可逆的那一步。按条数与天数保留（填 0 即不限）。

## 截图记忆
默认关闭。第一次产生可索引的截图（成品写进历史：直接存成文件、标注窗保存，或开了「未保存的截图也进历史」的兜底归档）时弹一次「开启截图记忆？」，
四条写清边界：只索引你主动截的图、只在本机、不上传不录屏、可随时关闭并清空；默认与 `Esc` 都停在「暂不」，点它只丢掉这一次、之后不再追问。
之后可在记忆库页点「开启记忆」，或到通用页勾「截图记忆：只索引我主动截的图」；手动开启只索引之后的新截图，旧图要走「导入旧截图」。
关掉开关立刻停止建立新索引与后台识别，已有索引仍可搜索，也可以随时清空。

索引什么：每张进入历史的截图记 OCR 全文（按 UTF-8 最多 64 KiB，超出截断）、文件名、应用进程名、窗口标题、截图时刻与像素尺寸；
窗口信息只在截图动作开始时取一次前台窗口，不轮询、不常驻监听。只复制到剪贴板或只贴到屏幕上的那一次没有文件，也就没有历史与索引
（开了未保存归档的除外）；回溯缓冲帧与录屏成品都不进记忆库。OCR 文本只在内存里参与匹配并写进本机数据库，不写日志、不上传。
中文按逐字切分进 FTS5：「报价」能命中「本周报价表」，多个词之间是「都要命中」；窗口标题、应用名与文件名也在可检索文本里。

搜索与筛选：记忆库页顶部搜索框按关键词查，右侧应用下拉按索引里出现过的进程名筛选（导入的旧图没有进程名，归到「未知应用」），
时间下拉给全部 / 今天 / 7 天 / 30 天；「合并重复图」默认开。单次最多回 200 条，顶到上限时页脚提示收窄关键词；
没有关键词时按时间倒序，有关键词时按相关度排。卡片上是 OCR 摘要、应用、标题、相对时间、尺寸与识别状态；识别中写「待识别」，
失败写「识别失败」，原图不在了写「文件已不在」。列表空了按「未开启 / 还没有索引 / 没搜到」分别给一句引导。

重复合并按每张图的 64 位 dHash 比：当前结果页里 Hamming 距离不超过 4 的条目并成一组，组头写「N 张重复/相似 · 最新 …」，
默认只露出最新一条，点组头展开或收起。分组只作用于当前这一页结果、不改数据库，关掉开关就逐条列出。
相似版式（同一页面滚动几行、同一窗口换个提示）也可能被并进一组，展开看一眼就能分辨。

旧图导入：点「导入旧截图」选一个文件夹，递归扫描 `.png` / `.jpg` / `.jpeg` / `.bmp` / `.webp`（不区分大小写、不跟符号链接、
单文件不超过 100 MiB）；已在索引里的同一路径跳过，其余按文件修改时间入库、应用与标题留空，识别排在新截图之后。
进度框报已扫描、已入库、跳过与失败，可随时取消——取消只停后面的文件，已入库的条目与已完成的识别都保留；同一时间只跑一个导入任务。
导入不复制文件、也不写历史；原图移动、改名或删除后，下一次进记忆库页会把这些索引行清掉并报条数，所以请让导入的图留在原路径。

动作与删除：选中一张可「贴图」「打开文件」「打开所在目录」「重新识别」「从记忆库移除」。文件已不在时贴图与打开灰掉；
「重新识别」只重置这一条的识别状态，旧文本留到新结果覆盖。「从记忆库移除」只删这一行；历史页删一条会删掉这条历史记录
与对应截图来源的索引行；清空历史会删掉全部历史记录与截图来源的索引行（导入来源的行保留）。两种历史删除都不动磁盘上的原图。
页脚「清空索引」只删全部索引行并回收文件空间，确认框写明条数，原图与历史记录都不动；进记忆库页时也会自动清掉原图已不在的行。

排除应用：「排除应用…」列出索引里出现过的应用与条数，也可以输入尚未出现过的进程名。保存时新排除的应用已有的索引先删掉
（弹确认框写明条数），之后这些应用的新截图不再入库；重新取消勾选只影响之后的截图，删掉的行不回填。导入的旧图没有进程名，不受排除影响。

容量与数据库：索引最多 10,000 条，超出后先淘汰最旧的导入条目、再淘汰最旧的截图条目，并提示淘汰条数；被淘汰的只是索引，原图不动。
页脚报总条数、待识别、失败、数据库大小（含 `-wal`）与排除应用数。数据库是程序数据目录下的 `memory-index.sqlite`（SQLite，WAL 模式）；
清空时 `VACUUM` 收缩，空闲页里的文本由 `secure_delete` 抹掉。数据库不额外加密，只依赖 Windows 用户目录的访问权限——
同一个 Windows 账户下的其他程序能读到这份索引，需要更强保护时请自行启用系统磁盘加密（如 BitLocker）。
数据库打不开或损坏时页面给中文原因与「重建索引」：旧库改名成 `memory-index.corrupt-<时间戳>.sqlite` 留档，再建一个空库，不静默删除。
识别后端不可用时页面会说明，截图仍先入库并保持待识别，后端恢复后可重新识别。

性能读数（本机 Release，2560×1440 单屏）：1 万条索引、5 个中文关键词各查 4 次共 20 次，平均 16 ms；500 张旧图导入 +
后台识别收口 + 三页检索合计 8.1 秒。产品目标是 1 万条查询 Release ≤200 ms、Debug ≤2 s，500 张导入与检索 ≤10 秒；
用例当前分别断言 200 ms / 2 s 与 <60 秒，所以 11–59 秒的回归不会被用例拦住。方法与读数见[路线图](Roadmap.md#截图记忆phase-3已实现)。

已知限制：

- OCR 漏字、旋转、低分辨率与艺术字都会让关键词搜不到；文件名、应用、标题与时间仍可兜底。
- 中文逐字分词会放大索引体积；10,000 条与单条 64 KiB 是硬上限。
- dHash 阈值 4 会把相似版式合并成一组，见上面「重复合并」；它只是提示，展开就能看到全部。
- 导入的旧图依赖原路径；移动、改名或删除后从索引消失，外接盘没挂载时同样按「文件已不在」处理。
- 不索引回溯缓冲帧与录屏帧，也没有全时记录、后台持续截屏或轮询前台窗口。
- 搜索是字面匹配：没有语义/向量搜索，也没有手动标签。
- 数据库未额外加密，只有 Windows 用户配置目录的权限；共用同一 Windows 账户的人能读到索引内容。

摆出来（点那行文字用系统浏览器打开）。**这是程序唯一的联网点**，不是启动就查；只做「查」不做「换」，
理由见[路线图](Roadmap.md#路线图后续计划)。


## 键位表

全局热键表在 [README](../README.md#全局热键)；下面是截图遮罩、标注窗与贴图窗三扇窗的窗内键。

截图遮罩上：

| 键 | 作用 |
| --- | --- |
| `Enter` / 双击 | 确认键盘造出的选区（鼠标拖框松手即交出；范围要在标注窗里用「选择」档拖四边重裁） |
| `方向键` | 已框好的选区整块平移一格 |
| `Shift`+`方向键` | 选区右下角挪一格（改大小） |
| `Ctrl`+`方向键` | 把那一侧的边外扩一格，对边不动（差一像素时不必重框） |
| `Ctrl+Shift`+`方向键` | 把那一侧的边往里收一格；已经是一格就停住，贴着屏边也不越界 |
| 拖框时按住 `Shift` | 锁正方形：对着图标、圆形按钮这类直角目标拖得出正好的等边（贴到屏边时夹完仍是正方形；松手那一刻也保持，不会弹回长方形） |
| 拖框时锁着比例（见下） | 按锁住的长宽比拖：光标拖到哪，就从起手点朝那一侧铺一块盖住光标的同比例框，贴边收缩后比例不变 |
| `A` | 锁 / 解长宽比：锁上时取当前选区的比例（先框一个相近的再按），没有选区就用上一次锁过的；锁上后跨轮次记住，再按一次解开并清掉 |
| `S` | 开尺寸输入框（预填当前选区尺寸，按设置里「尺寸单位」那一档给数，框的提示会写明是哪一档）：敲「宽x高」回车应用（左上角不动、越界夹回屏内），或敲「x,y,宽,高」连位置一起指定（与配置里那条选区记录同一套写法），`Esc` 或点画布取消；两种都不认就留在框里继续改 |
| `Ctrl+A` | 选中整块屏 |
| `R` / `Shift+R` | 在最近几次截图的选区之间循环挑（按最近在前排，最多记 5 条；`Shift+R` 反向）；换一块不用重框 |
| `,` / `.` | 悬停认出的界面元素往上 / 往下走一级；`,` 越过最外层就是整扇窗口，与悬停认窗接上（平台认不出元素时这两键不生效） |
| `I` | 元素拾取模式下复制元素信息（普通截图无效果） |
| `V` | 把当前选区的宽高复制进剪贴板，按设置里「尺寸单位」那一档给数（默认逻辑格，与遮罩读数同一口径；拨成物理像素就是会被裁出来的那一组数） |
| `C` | 放大镜读数里颜色那一格换一种写法：HEX → RGB → HSL → HSV → HSI → 十进制轮换（只影响这一次截图，不写回设置）；HEX 那一形里字母的大小写跟着设置里那一格走，不在这轮轮换里 |
| `P` | 翻这一轮的「成品含鼠标指针」：只改这一轮、不写回配置，读数后面标出「（含指针）/（不含指针）」。截菜单与悬停提示想带指针、下一张想要干净的，都不必先去设置里改两趟；滚动长截图那一轮没有这一档（按帧接图会把一枚指针复制成一串），这时 `P` 交回系统 |
| `Esc` | 取消 |

表里那六颗可换的裸字母（`A` `S` `R` `V` `C` `P`）都能在快捷键页最后一栏换成别的键，`R` 的 `Shift` 反向挡跟着一起搬；
`,` 与 `.` 不给换——符号键不在允许集合里（不同键盘布局上落点不同），而且它们是一对，改一颗另一颗就配不成对。
`Enter`、`Esc`、`I`、方向键与带 `Ctrl` 的那几组同样不给换：可换清册只收那六颗裸字母，这几组不在册内
（`Ctrl` 组合另有全局热键的允许集合管着，`Enter`/`Esc` 是确认与取消的固定出口）。

标注窗：

| 键 | 作用 |
| --- | --- |
| `Enter` | 复制到剪贴板 |
| `F5` | 刷新截图：重抓这一块区域换上，标注、选中与撤销历史都留着；按住不放由键盘自动重复兜住，一直刷到画面追上为止 |
| `V` `R` `E` `A` `P` `H` `M` `B` `T` `N` `L` `X` `G` `F` | 直接切到那一档工具：选择 / 矩形 / 椭圆 / 箭头 / 画笔 / 高亮 / 马赛克 / 高斯模糊 / 文字 / 序号 / 直线 / 橡皮擦 / 折线 / 放大镜（取英文名首字母，选择档用 `V`；裸按才认，带 `Ctrl` 的字母仍归原来的组合键；橡皮擦的 `E` 被椭圆占着，用的是中文首字母 `X`。这十四颗都能在快捷键页最后一栏换成别的键，换过之后按钮上的提示跟着改，见上「界面里的按键也能换」） |
| 序号工具在用时的 `+` / `-` / `0` | `+`/`-` 改当前计数组的下一个号（从那个号连排：5、6、7…），`0` 回到「按现有条数 +1」的自动编号；别的工具在用时不认这几键 |
| `Ctrl+S` | 保存 |
| `Ctrl+P` | 打印：开系统打印对话框，按纸面等比居中画上去；打印不关窗——取消对话框或在打印之后接着改，现场都留着（别的出口交完就收场） |
| `Ctrl+D` | 贴到屏幕上 |
| `Ctrl+O` | 送去文字识别 |
| `Ctrl+Z` / `Ctrl+Shift+Z` 或 `Ctrl+Y` | 撤销 / 重做 |
| `Delete` / `Backspace` | 删掉选中的标注（多选时整组一起删，一步撤销） |
| `方向键` | 选中的标注挪一格 |
| `Shift`+`方向键` | 选中的标注挪十格 |
| `Ctrl+C` / `Ctrl+V` | 复制选中的标注 / 粘贴副本；一条都没选中时 `Ctrl+C` 复制整张成品，与回车同一条路 |
| `Ctrl+回车` | 文字输入框里落定这一条（框里回车只换行、`Esc` 取消；输入时按键都归输入框，上面这些界面快捷键不抢） |
| `Ctrl+Shift+↑` / `Ctrl+Shift+↓` | 选中的标注上移 / 下移一层（已经在顶 / 底时按了不做事，也不占一格撤销） |
| `Ctrl+Shift+Home` / `Ctrl+Shift+End` | 选中的标注置底 / 置顶 |
| `Esc` | 关闭 |

贴图窗：拖动即移动，滚轮缩放，`Ctrl`+滚轮旋转，`Shift`+滚轮调透明度，`R` / `Shift+R` 转正一挡（90°），
`0` 回到原始比例与角度（透明度保持不动），左键双击关掉这一张，`H` / `V` 左右、上下翻转，`G` 灰度显示，`I` 反色，
`T` 缩到小图 / 还原，`Esc` 关闭，右键出菜单
（「缩到小图」那一项与 `T` 同一条路，四档视图变换各有一项）。
四边与四角也能拖：光标挨着边就换成那一条边的双头箭头，按住拖就是等比改大小（对面那条边钉住，与滚轮同一档倍率）；
缩成小方块的那一档，拖它的边就是在给那枚方块定大小（24 到 240 像素之间，中间那一按一拖仍是挪它）。
`方向键` 把这一张逐像素挪走（一格）、`Shift`+`方向键` 走十格——与遮罩、标注窗同一张键位表，多选时整组一起跟上；
`Ctrl+V` 用剪贴板里那一份换掉这一张（图像 / 文本卡片 / 颜色卡片都能换，摆位与倍率不动；动图会当场说明为什么不换）。
`Ctrl+A` 把桌上看得见的贴图一起选进多选集；拖动时按住 `Shift` 就是把这一张对到别的贴图或屏上窗口的边线上（松手即落定）。
上面那六颗裸字母（`R` `H` `V` `G` `I` `T`）都能在快捷键页最后一栏换成别的键，`R` 的 `Shift` 反向挡跟着一起搬；
`0`、`F5` 与带 `Ctrl` 的那几组不给换（回到原样、刷新这一张、粘贴与全选都是固定入口）。
没绑定的字母一律交回 Qt，贴图窗不抢输入法与系统快捷键。

## 设置与配置文件


设置窗口左侧按类别竖排：通用 / 截图 / 标注 / 贴图 / 录屏 / 文字识别 / 快捷键 / 主题 / 关于 / 历史，
每页顶部一句说明写清这一类管什么；每一页都裹在滚动区里，行多的那种（快捷键页四十来行）在默认窗口高度下往下滚就是。
主窗口的位置与大小也记住：下次启动开在关掉时那一处，换了屏或拔了屏由 Qt 挪回可见区。除界面语言（重启后生效）外，改完立即写入配置：
截图完成后做什么（进标注窗 / 复制到剪贴板 / 直接存成文件 / 直接贴到屏幕上 / 直接识别文字）、延时截图的秒数、截图后运行的外部命令、
截图含不含鼠标指针、成品存成 PNG / JPG / WebP 与有损档的质量、**成品文件名的模板**、取色复制用的写法与 HEX 字母的大小写、标注默认线宽与字号、贴图默认不透明度、录屏范围与输出格式、默认帧率与光标高亮，
从下一次截图、新建标注窗、新贴一张图、下一次开始录屏时起用。
文件名模板的变量有六个：`%date%`（yyyyMMdd）、`%time%`（HHmmss）、`%ms%`（三位毫秒）、
`%app%`（应用名）、`%title%`（窗口标题）、`%monitor%`（屏幕名），其余原样写进名字；
三个上下文变量取不到的回落值与清洗规则见[截图](#截图)；输入框下面的「预演：…」随输入即时更新。
截图、贴图右键的「保存」、识别结果导出与录屏成品共用这一格，留空即默认档（`GyanisScribe_%date%_%time%_%ms%`）。
填歪了（含路径分隔符、认不出的变量）不会写进配置，格子里的提示会说明原因；模板里去掉 `%ms%` 之后同一秒连拍会同名，
这时候后一张自己让位成 `…-2`，不覆盖前一张。
「通用」页还管着历史保留多少条、多少天（填 0 即不限）、**开机时自动启动**（写当前用户的启动项，不需要管理员；
状态读的就是系统里那一条，不在配置里另存一份，所以用户在系统「启动」设置里手动改过之后这里跟着变），
以及「导出配置… / 导入配置…」——
把全部设置写成一个 JSON 文件，换机器与备份时用；导入后订阅配置的热键与主题立刻跟上新值，
而当前那一页显示的还是导入前的值，关掉设置窗重开就对新。

| 用途 | 位置 |
| --- | --- |
| 配置 | Windows 注册表 `HKCU\Software\Gyanis\GyanisScribe` |
| 配置（便携模式） | 程序目录旁放一个空的 `portable.txt`，配置就改读写同目录下的 `GyanisScribe.ini`——启动日志里会写明「便携模式」；**只有配置跟着走**，日志、历史、缓存与成品目录仍在下面各自的位置（要连数据一起带走得另立一套根路径设计，见[路线图](Roadmap.md#路线图后续计划)） |
| 截图默认目录 | 用户图片目录下的 `GyanisScribe/`（可在设置里改） |
| 录屏默认目录 | 用户视频目录下的 `GyanisScribe/`（可在设置里改） |
| 日志 | `<AppData>/Gyanis/GyanisScribe/logs`，每条都是中文，界面切成英文也不翻译日志 |
| 崩溃转储 | 同一个日志目录下的 `GyanisScribe_<版本>_<时刻>_<进程号>.dmp`；反馈时把日志与这份一起发回来才定位得动 |
| 贴图恢复数据 | 缓存目录里的像素文件，配置里只存路径与几何 |

界面文案是中文，走 `Base::uiText()` / `Base::uiTextUtf8()`；英文档需要
`translations/GyanisScribe_en.qm`（随包分发，缺包时按中文继续并给出放置位置）。
翻译目录 `translations/GyanisScribe_en.ts` 是唯一真源，`.qm` 由构建期的 lrelease 产出。
改完文案要重新生成目录：

