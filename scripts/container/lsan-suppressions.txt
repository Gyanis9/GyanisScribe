# LeakSanitizer 抑制表：只放过系统库内部的字体/字形缓存，不放过本工程的分配。
#
# 为什么会有这份表：Qt 的字体引擎在首次排版时向 fontconfig 要一份 FcPattern 缓存，
# 那份缓存按设计活到进程结束（libQt6Gui/libfontconfig 内部持有），LSan 会把它报成泄漏。
# 我们不改系统库、也不因此关掉泄漏检测：detect_leaks 仍然开，本工程自己的分配照样会被报出来。
# 判据：报栈里若出现本工程的 src/ 帧，就不该写进这张表。
leak:libfontconfig
leak:QFontEngineMultiFontConfig
leak:QFontEngineMulti::stringToCMap
